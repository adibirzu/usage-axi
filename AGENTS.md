# usage-axi

- Data only: report [declarative routing evidence](src/routing.ts); never select, switch or recommend a route, record task events, refresh credentials, mutate providers or prompt interactively. Never emit or store credentials or account identity. Only percentages, window bounds, reset times and pool model IDs leave the tool; preserve the privacy regression in [quota-axi tests](test/sources/quota-axi.test.ts).
- Preserve the additive quota-axi envelope accepted unchanged by Firstmate's selector. Default `--json` retains the 15 selector fields asserted by [CLI tests](test/cli.test.ts); `--full` adds provenance and pool model IDs. [Types](src/types.ts) and [rendering](src/render.ts) own the exact shape; TOON remains the default.
- OpenUsage windows win; quota-axi may supply semantics only without dangling window joins, or fill providers with zero OpenUsage windows. OpenUsage cache-TTL stale is not selector evidence-stale: retain it separately as `state.cacheStale`. Failed adapters must remain visible in `sources[]`. Read [merge rules](src/sources/index.ts) and the [OpenUsage adapter](src/sources/openusage.ts) before changing this behavior; that adapter also owns provider aliases and the cache-first, no-`--force` timeout policy.
- Machine capacity counts process-tree invocation roots, excluding this probe tree and Cursor worker daemons. This intentionally differs from Firstmate's per-process count; do not claim parity or edit Firstmate here. Keep `machine.roots` auditable and snapshot processes before starting probes. [Machine fixtures](test/fixtures/machine/README.md) explain capture and drift; redact prompts and credentials from argv captures.
- Tests use fixture seams, without requiring installed upstream tools. [Acceptance tests](test/acceptance.test.ts) exercise selector parity; the vendored [selector](test/support/fm-dispatch-select.mjs) is a pinned, read-only MIT reference. The real upstream selector is authoritative; re-vendor only for a deliberate contract change.
- Preserve exit meanings: 0 success, 1 no provider data (or no doctor source), 2 usage error. No-data exit 1 from quota-axi is valid input, not a parser failure or fabricated healthy quota; see its [adapter](src/sources/quota-axi.ts) and [executable regressions](test/quota-axi-cli.test.ts).

[package.json](package.json) owns commands and tool versions. Generated skill guidance must defer to current CLI behavior rather than copy provider inventories.
